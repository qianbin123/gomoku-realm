# Gomoku Realm — WebXR Codex MVP task kit

Planning/task documents only, **not game code**.

## How to start
1. Extract into a new private Git repository directory named `gomoku-realm` (or copy these files into your existing project root).
2. Run `git init` if not already a repository, then run `codex` inside that directory.
3. Paste `CODEX_START.md` as the first request.
4. Let Codex finish TASK-001; later tell it to implement TASK-002 and TASK-003 sequentially.
